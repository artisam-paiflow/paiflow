# Agent instructions

Read [CLAUDE.md](CLAUDE.md) for repository commands, architecture, conventions, and
contribution workflow before making changes.

Follow [docs/releasing.md](docs/releasing.md) when preparing a release or changing a
public interface. It is the source of truth for app, API, and SDK versioning.
Record noteworthy changes in [CHANGELOG.md](CHANGELOG.md) under `Unreleased`.
Ordinary commits do not require an app version bump; preparing a release does.
